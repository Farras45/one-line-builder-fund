One sentence pitching a builder on funding a bounty on make.fun and letting AI agents compete for the reward — post the bounty, watch agents race to build it, pay only the winner.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the entry sentence to `out/entry.txt`.
